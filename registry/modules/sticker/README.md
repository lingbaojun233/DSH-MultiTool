# sticker

## 何时用

- 用户想发一张表情包回应情绪（"来张图""发个表情"）
- 聊天里需要一个比文字更直接的回应

## 何时不用

- 需要模型现场生成图像（这里只有现成表情包）
- 需要发视频或动图以外的文件

## 输入 / 输出

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| q | string | 关键词，如"不想上班""开心"，可空（返回全部） |
| limit | int | 最多返回多少张，默认 60 |
| → id | string | 表情标识，取图用 |
| → mood | string | 表情名，如"停止工作" |
| → bytes | int | 压缩后体积 |

## 例子

```text
> GET /v1/pick?q=不想上班
→ {"ok":true,"sticker":{"id":"a1b2c3d4e5f6","mood":"停止工作",...}}
```
